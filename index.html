Professional Growth and Career Development

Throughout my Bachelor of Science in Computer Science program at Southern New Hampshire University, I have developed the technical knowledge, problem-solving abilities, and professional skills necessary to transition into the computer science industry. My academic experience has strengthened my understanding of software engineering, algorithms, data structures, database management, cybersecurity, and application development. More importantly, it has taught me how to apply these concepts to real-world problems while considering reliability, efficiency, maintainability, and the needs of end users.

My professional background as a Staff Sergeant in the United States Marine Corps has significantly influenced my approach to computer science. As a Communications Chief, I have been responsible for supervising 16 Marines, maintaining accountability of approximately $2.65 million in communications equipment, and supporting mission-critical communications systems. These responsibilities have required technical troubleshooting, operational planning, leadership, risk management, and effective communication with personnel possessing different levels of technical expertise.

Throughout my degree program, I recognized that many of the skills I developed in the military translate directly into software development and information technology. Troubleshooting communications networks requires systematic analysis, identification of potential failure points, implementation of corrective actions, and verification of results. These same principles are fundamental to software debugging, system testing, and technical problem-solving.

Completing my computer science degree and developing this ePortfolio have helped me establish a clearer professional direction. My goal is to combine my experience in military communications and networking with my education in computer science to pursue opportunities in technical systems support, software engineering, networking, and cybersecurity.

Software Engineering and Development

Throughout my coursework, I gained experience developing applications using Java, C++, Python, JavaScript, and supporting development frameworks. These projects strengthened my understanding of object-oriented programming, modular design, software testing, debugging, and application architecture.

One significant example is the Android Inventory Application I originally developed in CS 360, Mobile Architecture and Programming. The project introduced me to mobile application development and the importance of designing software around practical user requirements.

During my capstone, I revisited this application to improve its software engineering quality. I focused on strengthening input validation, improving maintainability, and expanding automated testing. The enhanced application demonstrated measurable improvement in testing coverage, increasing from one automated unit test to five, with all five tests passing.

This enhancement reinforced the importance of treating testing and validation as integral parts of software development rather than activities performed only after implementation. It also demonstrated how revisiting an existing application can reveal opportunities to improve its reliability and long-term maintainability.

Algorithms and Data Structures

My coursework in algorithms and data structures taught me how to evaluate computing solutions based on performance, efficiency, and suitability for a particular problem. I learned that selecting an appropriate data structure can significantly influence how effectively an application manages and retrieves information.

For my capstone, I enhanced a C++ course-planning application by incorporating an AVL tree. This self-balancing binary search tree provides efficient search, insertion, and retrieval operations while maintaining a balanced structure.

The enhancement also included recursive prerequisite processing, stronger input validation, and automated testing. I verified the improved implementation using a test suite containing 20 tests, all of which passed.

This experience strengthened my ability to evaluate algorithmic trade-offs, implement more sophisticated data structures, and verify that improvements do not compromise existing functionality.

Enhancement Two: Algorithms and Data Structures

Artifact: C++ Course Planner

Original Course: CS 300 – Data Structures and Algorithms

Technologies: C++, AVL Trees, Recursive Algorithms, CSV File Processing, PowerShell

Original Artifact

The original Course Planner provided a way to load course information, locate courses, and display prerequisites. It served as a foundation for examining how data structure selection affects lookup efficiency and how course relationships can be validated.

Enhancement Overview

For my CS 499 capstone, I enhanced the Course Planner by implementing an AVL tree, a self-balancing binary search tree. By maintaining a balanced structure after insertions, an AVL tree supports worst-case O(log n) search and insertion operations, avoiding the O(n) worst-case behavior of an unbalanced binary search tree.

I also added recursive prerequisite processing to display prerequisite relationships, along with stronger CSV input validation. These changes address problems such as malformed course records, missing prerequisite references, duplicate course identifiers, and circular prerequisite relationships.

Testing and Verification

I verified the enhanced Course Planner with an automated suite of 20 tests, all passing. The tests covered AVL rotations and invariants, prerequisite traversal, and file-loading validation, including ensuring invalid input does not corrupt the existing catalog.

Verification command:

.\run_tests.ps1
